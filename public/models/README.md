# Photoreal 3D Models Directory
Place your optimized .glb files here named by instrument ID:
e.g. guitar.glb, violin.glb, piano.glb, flute.glb, saxophone.glb, etc.

To automatically source Creative Commons photoreal models from Sketchfab:
1. Add your token to .env:
   SKETCHFAB_API_TOKEN=your_token_here
2. Run:
   npm run fetch:models
